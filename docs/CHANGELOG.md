# تغییرات lobby-sdk

## 0.4.1

- معرفی روشن SDK به‌عنوان رابط اوینا با لابی اختصاصی بازی، مستقل از موتور.
- راهنمای متمرکز دریافت اطلاعات مدل، تکسچر، لباس و اکسسوری آواتار در `08-avatar-data.md`.
- توضیح مسئولیت بازی در دانلود، Draco، نمایش، انیمیشن، cache و پاکسازی منابع.
- مثال APIهای موجود برای رویدادهای اتاق، تغییر ظاهر، شخصی‌سازی و تطبیق snapshot پس از reconnect.
- حذف ارجاع‌های گمراه‌کننده به لابی آماده از مسیر اصلی مستندات.
- اصلاح توضیح پکیج؛ بدون تغییر API یا منطق اجرایی نسبت به نسخهٔ 0.4.0.
