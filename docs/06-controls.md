# ورودی و حرکت در لابی اختصاصی

کنترل صفحه‌کلید، لمس، دوربین، فیزیک و انیمیشن با موتور و کد خود بازی است. SDK آن‌ها را ایجاد یا جایگزین نمی‌کند.

بعد از محاسبهٔ وضعیت کاربر در بازی، وضعیت لازم را با API موجود ارسال کنید:

```ts
client.sendMove({
  position: { x: 0, y: 0, z: 3 }, // موقعیت واقعی محاسبه‌شده در بازی شما
  rotationY: 0,
  animation: 'idle',
});
```

حرکت دریافتی از `player:update` را روی نمایش همان userId اعمال کنید. دادهٔ `animation` یا رویداد `player:emote` را به انیمیشن‌های موتور خودتان نگاشت کنید؛ دریافت داده به معنی پخش خودکار انیمیشن نیست.

برای خود کاربر، کنترلر حرکت بازی را منبع موقعیت نگه دارید. هنگام خروج، listenerها و منابع UI/صحنهٔ خودتان را همراه اتصال SDK پاک کنید.
