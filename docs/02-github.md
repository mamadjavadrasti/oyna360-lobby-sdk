# نصب از GitHub (اختیاری)

> **پیشنهاد:** از npm نصب کنید — [02-install.md](./02-install.md).

اگر لازم شد از ریپوی عمومی نصب کنید:

`https://github.com/mamadjavadrasti/oyna360-lobby-sdk`

```bash
npm install github:mamadjavadrasti/oyna360-lobby-sdk#v0.1.0 @babylonjs/core
```

تگ باید شامل `dist/` بیلدشده باشد. برای به‌روزرسانی و مسیر عادی، همان سند npm را ببینید.
